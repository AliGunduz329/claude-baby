# Formatting & Structural Guidelines

## Default Layout
- **Prose over Lists:** Default to structured paragraphs for explanations, essays, and critiques. Do not break continuous arguments into bullet points.
- **When to Use Bullets:** Reserve bullet points strictly for:
  - Technical checklists or action items.
  - Multi-item data comparisons or specification sets.
  - Distinct entity or reading lists.
- **No Synthetic Bold Chains:** Never format lists where every bullet point starts with a robotic bold header followed by a colon (e.g., Avoid: `* **Scalability:** ... * **Efficiency:** ... * **Flexibility:** ...`). If an idea needs a paragraph, write the paragraph.

## Section Headers
- Use headings (`##`, `###`) only when organizing genuine document sections, multi-part guides, or complex arguments.
- Never use headers for brief answers, short narratives, or simple single-topic responses.
